# 非编码项目通用验收清单 L0–L4（`validation-checklist.md`）

> 适用：`project-profile.projectType = content`（绘图、剪辑、文档、小说、设计稿、PPT / 视频、单页 HTML 等）。
> 执行者分工：**L0–L2 + L4 写进 skill 内置通用检查（自动跑，不进预检单）**；**L3 由持久「审阅」队友按清单核对**，并抽查 L4。
> **审阅队友不做审美评审**。仅 **L2 的项目专属数值**（16:9、3 分钟、5 张图、主题、命名）需人睡前在预检单里定。

> **为什么不能「只查文件产出」**：会漏 0 字节、损坏无法解码、占位符残留、错尺寸 / 比例、数量不对、时长不对。五层逐层收紧。

## L0 · 存在性（脚本自动）

| # | 检查 | 通过判据 |
|---|---|---|
| 0.1 | 产物在任务卡约定的输出路径 | 路径精确匹配 `write_scopes` 前缀 |
| 0.2 | 文件非空 | `Length > 0`（0 字节直接 FAIL） |
| 0.3 | 数量符合任务卡 | 声明 N 个就恰好 N 个，不多不少 |
| 0.4 | 命名符合预检单约定 | 前缀 / 序号 / 扩展名一致 |
| 0.5 | 无临时 / 中间产物混进交付目录 | 交付目录只含最终产物 |

## L1 · 完整性（工具自动）

| # | 检查 | 通过判据 |
|---|---|---|
| 1.1 | 图片可解码且有尺寸 | 能读出宽高，尺寸 > 0 |
| 1.2 | 视频可读时长 / 帧率 / 可解码 | 有有效 duration，首帧可读 |
| 1.3 | docx / pptx / xlsx 可打开 | 能解析包结构，页数 / 工作表数 > 0 |
| 1.4 | PDF 可打开且页数符合 | 能取到页数 |
| 1.5 | HTML 无致命错误 | 无头浏览器 console 无新增 error（全局规范 §8：无头 Playwright） |
| 1.6 | 无截断 | 尾部结构完整（如 HTML 有闭合标签、视频有尾帧、文档有结束标记） |

## L2 · 规格（部分脚本 + 清单；专属数值来自预检单）

| # | 检查 | 数值来源 |
|---|---|---|
| 2.1 | 尺寸 / 比例（如 16:9、1920×1080） | **预检单里人睡前定的专属值** |
| 2.2 | 时长（如 3 分钟 ±5s） | 同上 |
| 2.3 | 页数 / 张数（如 5 张图） | 同上 |
| 2.4 | 主题 / 文案 / 关键字 | 同上 |
| 2.5 | 命名规则、序号连续性 | 同上 |

> 预检单没答的专属值 → 落回 `habits.md` §三 默认 + 记 `DECISIONS.md`（来源标 `默认表`），**不凭空编一个规格**。

## L3 · 内容合规（持久「审阅」队友按清单核对）

| # | 检查 | 通过判据 |
|---|---|---|
| 3.1 | 无占位符 | 不含 `TODO` / `TBD` / `lorem` / `ipsum` / `示例文本` / `placeholder` |
| 3.2 | 无空白帧 / 空白页 / 纯色占位 | 逐帧 / 逐页抽检 |
| 3.3 | 与任务卡描述一致 | 主题、对象、数量、顺序对得上 |
| 3.4 | 无前后矛盾（设定 / 人设 / 时间线） | 对照任务卡与 `context-pack` 的架构约定 |
| 3.5 | 无未替换的模板痕迹 | 无 `{{...}}` / `<your ...>` / 上个项目名 |
| 3.6 | 证据与本轮改动对应 | 证据时间戳属于本夜（防伪，见 `verification.md`） |

## L4 · 证据（自动落盘 + 审阅抽查）

| # | 检查 | 落盘位置 |
|---|---|---|
| 4.1 | 预览图 / 关键帧 / 首屏截图存在 | `night-shift/evidence/<日期>/<任务 id>-<用途>-<HHmmss>.png` |
| 4.2 | 截图非空、能解码、与产物对应 | 同上 |
| 4.3 | 校验清单本体的输出（含统计行） | `night-shift/evidence/<日期>/<任务 id>-checklist.log` |
| 4.4 | 证据带本次运行时间戳 | 文件名 + 内容均含时间戳；**复用旧证据 = 证据造假** |

## 结论格式

「审阅」队友只出结构化结论（见 `team-mode.md` §5）：

```
RESULT: PASS | FAIL
task: <task id>
layers: L0 ✅ / L1 ✅ / L2 ✅ / L3 ✅ / L4 ✅   （逐层标注）
issues: <FAIL 时逐条写文件:行号 / 与哪条不符>
suggestion: <可执行的修改方向，不做审美评审>
```

## 不适用 / 交白天

- 二进制产物（docx / pptx / mp4 / png）**无法 diff / 自动合并** → 冲突一律 `blocked` 交白天。
- 审美、风格、创意取舍**不在本清单内** → 留白天人工裁定。
- 非编码产物的**最终交付 / 发布**留白天（见 `team-mode.md` §8）。
